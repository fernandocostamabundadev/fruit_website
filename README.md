# Fruit — Frescura da colheita

Site responsivo para uma marca de fruta fresca, com conteúdo em português de Portugal, apresentação renovada e animações suaves.

## Funcionalidades

- Apresentação de fruta e conteúdos adaptados a telemóveis e computadores.
- Navegação acessível por teclado com menu para dispositivos móveis.
- Alternância entre tema claro e escuro, com preferência guardada no navegador.
- Animações de entrada e efeitos de interação, respeitando a preferência por movimento reduzido.
- Formulário de novidades com confirmação local.

## Executar

Abra `index.html` num navegador. Não é necessária instalação.

## Nota sobre o formulário

O formulário serve apenas para demonstrar a interação na página. Não envia nem guarda dados pessoais.
